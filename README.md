# Alerta Vecinal 26 · Central de Monitoreo

Central de monitoreo web de Alerta Vecinal 26 para la Municipalidad Distrital de Veintiséis de Octubre (Piura).

Recibe en vivo las alertas de los celulares con la app, hace sonar la sirena hasta que el oficial a cargo la atiende, genera los códigos de autorización para serenos y policías, sigue por GPS a las unidades con la app abierta, envía las órdenes de cerco a sus celulares y muestra el mapa de calor y los reportes diario, semanal, mensual y anual.
